# Wolfman Local

## How do I install these formulae?

`brew install wolfman/local/<formula>`

Or `brew tap wolfman/local` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "wolfman/local"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
